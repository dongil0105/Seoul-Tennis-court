# 어사이드(Aside)에 붙여 넣을 지시문

어사이드는 내 컴퓨터에서 도는 AI 브라우저라서, 클라우드에서 도는 Claude 가 직접 조종할 수 없다.
대신 아래 지시문을 어사이드에 그대로 붙여 넣으면 어사이드가 유튜브 영상을 보고 **정해진 형식의 기록**을 만든다.
그 기록 파일을 Claude 대화에 올리면 국면별 지식(`docs/coach/phase_knowledge.json`)과 교정 이론에 반영한다.

- 한 번에 너무 많이 시키면 대충 본다. **한 번에 영상 5~10개**씩, 스트로크 하나씩 나눠서 시킨다.
- 어사이드가 만드는 것은 글(관찰 기록)이다. 뼈대(관절 위치) 학습에는 내 영상의 '진단 파일'이 필요하다.

## 0) 화면 보고 학습 — 유튜브를 틀어 두면 스윙 코치가 보며 배운다 (가장 먼저 할 것)

관절 움직임으로 배우는 길이다. 영상은 저장하지도 보내지도 않는다. 컴퓨터에서만 된다.

**내가 직접 한 번 할 일(브라우저의 공유 창은 사람이 눌러야 한다)**

1. 어사이드에서 잠금 해제 링크를 한 번 연다(처음 한 번).
2. 새 창으로 https://seoul-tennis-court.onrender.com/coach/watch 를 연다. 이 창은 계속 보이게 둔다.
3. 다른 창(탭)에서 유튜브를 연다.
4. 스윙 코치 창에서 "① 볼 탭 고르기"를 누르고 유튜브 탭을 고른 뒤 "② 학습 시작"을 누른다.

**그다음 어사이드에 붙여 넣을 지시문**

```
유튜브 탭에서 아래 일을 해 줘. 스윙 코치 창("화면 보고 학습")은 건드리지 말고 그대로 열어 둬.

1. 내 구독 목록을 열어, 테니스를 다루는 채널을 모두 찾아 목록으로 적어 줘.
2. 그 채널들을 하나씩 열어 "동영상" 탭의 "모두 재생"을 눌러 처음부터 재생해 줘. 재생 속도는 1배속(보통), 화질은 720p 이상.
3. 광고·건너뛰기 버튼이 나오면 넘기고, 재생이 멈추면 다시 재생해 줘. 테니스가 아닌 영상(브이로그·인터뷰·장비 리뷰)은 다음 영상으로 넘겨도 돼.
4. 한 채널의 재생목록이 끝나면 다음 채널로 넘어가. 모두 끝나면 본 채널과 대략 본 영상 수를 알려 줘.
5. 30분마다 스윙 코치 창을 한 번 보고, "보는 중"이 아니거나 빨간 글씨 오류가 있으면 나에게 알려 줘.
```

- 한 가지 스트로크만 나오는 영상(예: 포핸드 드릴)을 볼 때는 스윙 코치 창의 "한 가지 스트로크만 나오는 영상인가요?"를 맞게 골라 두면 정답으로 쓸 수 있어 훨씬 도움이 된다.
- 보다가 끝내려면 스윙 코치 창의 "끝내고 보내기"를 누른다. 창을 닫아도 보관분은 남고, 다시 열면 이어서 보낸다.
- 어느 정도 봤으면 Claude 대화에 "가져가서 학습해"라고 하면 된다. 그때 스윙 코치 창이 열려 있어야 한다.

## 1) 레슨 영상 — 국면별 체크포인트

```
너는 테니스 코치 교육 자료를 만드는 조사원이야. 유튜브에서 아래 주제의 레슨 영상을 찾아서 직접 재생해 보고 기록해 줘.

주제: [포핸드 | 양손 백핸드 | 한손 백핸드 | 서브(플랫폼) | 서브(핀포인트) | 포핸드 발리 | 백핸드 발리 | 스매시 | 슬라이스] 중 "포핸드"
영상 수: 조회수가 많고 코치가 직접 설명하는 영상 8개 (한국어 4개, 영어 4개). 쇼츠·광고·하이라이트 모음은 빼.

영상마다 끝까지 보고, 자막이나 요약만 읽지 말고 화면에서 실제로 보이는 동작을 확인해서 아래 형식(JSON)으로 적어 줘.
모르는 칸은 지어내지 말고 null 로 둬. 코치가 말한 숫자(각도, 높이, 시간, 거리)는 말한 그대로 적어.

{
  "url": "", "title": "", "channel": "", "language": "ko|en", "stroke": "forehand",
  "level": "초보용|중급용|상급용",
  "camera": "정면|옆|뒤|여러 방향",
  "phases": [
    { "phase": "준비(스플릿)|테이크백|임팩트|피니시",          // 서브는 준비|토스|트로피|임팩트|피니시, 발리는 준비(스플릿)|임팩트|피니시
      "time": "mm:ss",                                         // 그 국면을 설명하는 영상 속 시각
      "checkpoints": ["몸의 어느 부위가 어디에 어떻게 있어야 하는지 한 문장씩"],
      "numbers": ["코치가 말한 숫자 그대로"],
      "common_errors": [ { "error": "동호인이 흔히 하는 실수", "why_bad": "왜 문제인지", "fix": "코치가 말한 교정법/드릴" } ]
    }
  ],
  "key_message": "이 영상에서 코치가 가장 강조한 한 가지",
  "seen_or_heard": "seen(화면에서 직접 확인) | heard(말로만 들음)"
}

8개를 모두 마치면 JSON 배열 하나로 묶어서 lessons_forehand.json 파일로 저장해 줘. 마지막에 영상들 사이에서 코치들 말이 서로 다른 부분이 있으면 따로 정리해 줘.
```

주제만 바꿔 가며 되풀이한다(파일 이름도 `lessons_backhand2h.json` 처럼 바꾼다).

## 2) 게임 영상 — 코트 뒤에서 찍은 동호인·프로 경기

```
너는 테니스 경기 분석원이야. 유튜브에서 "코트 뒤(베이스라인 뒤)에서 고정 카메라로 찍은" 테니스 경기 영상을 찾아서 직접 재생해 보고 기록해 줘.

찾을 것: 머드리 채널의 동호인 단식/복식 게임 영상 3개, 다른 채널의 동호인 게임 영상 2개, 프로 경기의 코트 레벨(뒤에서 찍은) 영상 2개.
영상마다 처음 3분만 보면 돼. 카메라에 가까운 쪽 선수(등이 보이는 선수) 한 명만 기록해.

{
  "url": "", "title": "", "channel": "",
  "camera": "코트 뒤 낮게|코트 뒤 높게|옆|기타", "match": "단식|복식", "level": "동호인 초급|동호인 중급|동호인 상급|선수",
  "player": { "hand": "오른손|왼손", "backhand": "한손|양손", "serve_stance": "플랫폼|핀포인트|모름" },
  "shots": [
    { "time": "mm:ss", "stroke": "서브|포핸드|백핸드|포핸드 발리|백핸드 발리|스매시|슬라이스|로브",
      "result": "인|아웃|네트|위너|모름",
      "coach_note": "코치라면 이 샷에서 무엇을 지적할지 한 문장(없으면 null)" }
  ],
  "patterns": ["이 선수가 되풀이하는 자세 버릇 2~3가지 (예: 테이크백이 늦다, 임팩트가 몸 뒤에 있다)"]
}

모르면 지어내지 말고 "모름"이나 null 로 둬. 모두 마치면 JSON 배열 하나로 묶어서 games.json 파일로 저장해 줘.
```

## 3) 영상 파일로 관절까지 학습 — 스윙 코치에 넣고 진단 파일 만들기

글이 아니라 **관절 좌표**로 배우는 길이다. 내 컴퓨터에 테니스 영상 파일이 있을 때(직접 찍은 것 포함) 쓴다.
스윙 코치는 영상을 내 브라우저 안에서만 분석하고, 진단 파일에는 관절 좌표와 설정만 들어간다(영상·파일 이름은 들어가지 않는다).
어사이드에서 스윙 코치를 처음 열면 '준비 중'으로 보인다 — 잠금 해제 링크를 어사이드에서 한 번 열어 둔다.

```
아래 일을 내 컴퓨터의 [폴더 이름] 폴더에 있는 테니스 영상 파일마다 되풀이해 줘. 영상 하나에 진단 파일 하나.

1. https://seoul-tennis-court.onrender.com/coach 를 연다.
2. '영상 올리기'를 눌러 영상 파일 하나를 고른다.
3. '누구의 스윙인가요' 화면에서 영상 속 선수에 맞게 고른다: 오른손/왼손, 한손/양손 백핸드. 알 수 없으면 오른손·양손 백핸드. 여러 사람이 나오면 카메라에 가장 가까운 선수를 고른다.
4. 분석이 끝나 결과가 나오면, 샷의 종류(서브/포핸드/백핸드/발리/스매시)가 영상과 다르게 적힌 것은 화면에서 맞는 종류로 바꾼다.
5. '분석이 틀렸나요? 진단 파일 저장'을 누르고, 적는 칸에 다음을 쓴다:
   영상 제목 / 찍은 방향(뒤·옆·정면 중 하나) / 수준(동호인·선수) / 영상에 한 가지 스트로크만 나오면 "포핸드만"처럼.
6. 저장을 눌러 swing-coach-diag-….json 파일을 내려받는다.
7. 다음 영상으로 넘어가 1번부터 되풀이한다.

끝나면 내려받은 json 파일이 어느 폴더에 몇 개 있는지 알려 줘.
```

- 영상은 3분 안쪽으로 짧은 것이 좋다(진단 파일 하나에 샷 40개·5분 분량까지만 담긴다).
- 저장된 json 파일들을 Claude 대화에 올리면 `tools/coach/diag_ingest.mjs` 로 풀어 시험하고 학습에 넣는다.
  4번에서 바로잡은 종류는 정답으로, 5번에 적은 "○○만"은 영상 단위 정답으로 쓴다.

## 받은 기록은 이렇게 쓴다

- 레슨 기록 → 국면별 체크포인트·흔한 실수·교정법을 `docs/coach/phase_knowledge.json` 에 합친다(출처와 '화면에서 확인/말로만'을 같이 적는다).
  여러 코치가 같은 말을 한 것만 앱의 조언 문장으로 쓴다.
- 게임 기록 → 동호인이 실제로 자주 하는 실수의 빈도를 센다(무엇을 먼저 알려 줄지의 우선순위). 샷 시각 기록은 사람이 본 정답으로 참고한다.
