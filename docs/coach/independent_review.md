# 독립 검수 기록 (스윙 코치)

구현과 따로, 코드만 받은 검수 에이전트가 읽기 전용으로 검토했다(판정: **수정 후 머지 가능**). 실제 헤드리스 브라우저 구동, 합성·실제 자세 시퀀스 탐침, 사진 육안 확인을 근거로 했다.
아래는 지적과 조치다.

## Critical

| 지적 | 조치 |
|---|---|
| **기준 자세 데이터 오염** — 제목이 `File:이름…` 으로 시작하면 선수를 못 알아봄(콜론), 그래서 남/여 분포가 하나도 없었음. 이름표의 손으로 순간이 안 잡히면 반대 손으로 다시 맞춰 보는 바람에 '토스하는 팔'이 임팩트 표본이 됨(확인된 것 15개). 1908~1940년 사진·어린이 사진·원본/잘라낸 판 중복 포함. | `tools/coach/names.mjs` 로 이름 인식 수정, 반대 손 재시도 제거(알려진 선수는 그 손, 모르면 오른손만), 서브 임팩트 규칙에 "반대 손은 내려와 있고 팔이 수직으로 붙지 않음" 추가, 1970년 이전·어린이 사진 제외, 거의 같은 자세 중복 제거, 공용 분류에서 이름·성별 읽기. 화면 표기는 "프로 선수" → "선수 사진". 테스트 `tests/js/coach_tools.test.mjs`. |
| **스윙이 아닌 동작에 단정적 조언** — 240p 시범 영상에서 테이크백·라켓 내리기를 임팩트로 잡아 38점과 "타점이 늦어요"를 냄. 비스듬히 찍은 영상을 옆 화면으로 보고 타점 cm 를 잼. 임팩트가 한두 장 늦어 "높은 공"으로 봄. 같은 사람의 샷이 96점/38점. | 백스윙→임팩트에서 손이 가슴 앞으로 나오지도 몸을 가로질러 넘어가지도 않으면 '의심' → 평가하지 않음(전체 영상에서는 버림). 옆 화면은 27도 안쪽일 때만, 그 밖은 '대각선'으로 두고 타점 cm 를 재지 않음. 높이·어깨 턴은 앞뒤 한두 장 중 너그러운 값 사용. 팔다리가 또렷하지 않으면(0.6 미만) 점수를 내지 않음. 같은 시범 영상 재검: 테이크백 5개는 평가 불가, 잘 보인 5개는 모두 같은 점수. |

## Major

| 지적 | 조치 |
|---|---|
| 자세 인식 엔진(MediaPipe 번들)이 `odml.pa.googleapis.com` 으로 사용 통계를 보냄(영상·좌표는 아님). 글꼴도 바깥 CDN. "밖으로 나가는 것은 선수 사진뿐"이라는 안내와 어긋남. | `/coach` 응답에 콘텐츠 보안 정책(`connect-src 'self'`) → 전송 차단을 브라우저로 확인(밖으로 나간 요청은 위키미디어뿐). 바깥 글꼴 제거. 테스트 추가. |
| 저장형 XSS — localStorage 의 내 정보(`heightCm`)를 검증 없이 화면에 끼워 넣음. | `cleanProfile`(허용 목록·숫자 범위), 기준 자세 `validRef`. 테스트 추가. |
| 취소·실패 뒤 뒤로 가기가 헛돎(기록에 같은 화면이 쌓임). | 취소·실패는 진행 화면을 기록에서 빼고 돌아감(`history.back`). |
| 긴 분석 중 화면이 꺼지면 영상 일부만 보고 결과를 냄. | 분석 중 화면 켜짐 유지(Wake Lock), 끝까지 못 읽었으면 "○초까지만 봤어요" 표시. |
| 인식기 인스턴스 3개를 닫지 않음(추정). | 스윙 영상과 정밀 분석이 같은 인스턴스를 쓰게 줄임(2개). |
| 스윙 영상에서 프레임마다 '가장 큰 사람'을 새로 골라 두 사람이 섞일 수 있음(추정). | 방금 그 사람과 가장 가까운 사람을 계속 따라가는 고르개(`Pose.sticky`). |
| 아이폰에서 재생 전에는 첫 화면을 안 읽어 영상 열기가 시간 초과될 수 있음(추정, 실기기 필요). | 메타데이터를 읽자마자 살짝 옮기고 소리 없이 재생을 걸어 깨움. **실기기 확인은 아직 못 함.** |
| 치는 손 설정이 틀려도 그대로 분석. | 반대 손목이 훨씬 빨리 움직였으면 결과 화면에서 알림. |

## Minor (조치한 것)

평가 불가일 때 2순위 조언·칭찬도 숨김 · 샷 화면에서 고친 뒤 목록 다시 그리기 · 지워진 결과 화면으로 앞으로 가기 방지 ·
엔진 import 에 버전 · 출처 표기에 자르기·덧그림 명시 · 서브 계산기의 "영상에서 잰 값" 표기는 범위 안일 때만 · 계산 오류 대비.

## 남은 것 (하지 않음)

- 실제 iOS·안드로이드 기기 검증, 휴대폰 메모리 실측, 1080p 휴대폰 영상에서의 오검출 비율 — 이 환경에서는 할 수 없었다.
- 기준 자세 표본의 수동 검수(사진을 하나씩 보고 순간이 맞는지 확인) — 자동 규칙만 강화했다.
- 큰 파일 압축 전송(gzip)과 Range 응답의 캐시 머리말.
- 전체 영상 모드는 서브 종류를 늘 플랫으로 보고, 슬로모션 배수를 1로 본다.
