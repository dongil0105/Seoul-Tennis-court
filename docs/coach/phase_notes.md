# 단계 지식 요약 (phase_knowledge.json 과 함께 본다)

**먼저 알 것 — 자막은 한 건도 못 읽었다.** PlayMCP 유튜브 도구로 자막을 읽을 계획이었지만 검색은 하루 한도 초과,
자막(get_transcripts)은 유튜브의 IP 차단으로 모든 영상에서 실패했다. 영상은 받지 않았다. 그래서 내용은
① 영상 설명란(앞 500자), ② 그 코치가 자기 사이트에 쓴 레슨 글의 검색 요약, ③ 검색 요약 조각, ④ amara.org 자막 조각(영상 2개)에서 왔다.
영상 86개를 찾아 id·채널·제목을 확인했고(영어 62, 한국어 24) 그중 52개(30개 채널)와 레슨 글 50개가 항목의 출처다.
출처 없이 넣은 17개는 `memory`. `measure` 칸은 코치 말이 아니라 뼈대로 재는 방법 제안이다. 좌우는 오른손잡이 기준.

## 준비(스플릿 스텝) — 포핸드·백핸드 공통
- 체크: 상대 임팩트 순간 두 발이 공중 → 임팩트~직후 착지 / 뛰기 시작은 상대가 앞으로 스윙할 때 / 높이 뛰지 않는 작은 홉 /
  착지 발 간격 어깨너비~어깨의 1.5~2배, 무릎 굽히고 앞꿈치 / 착지하며 바깥발을 공 쪽으로.
- 실수: 친 것을 보고 나서 뜀(늦음), 너무 일찍 착지, 아예 안 함, 자리 기준으로 스플릿.
- 한계: 상대 임팩트 시각이 없으면 타이밍은 못 잰다. 발이 떴는지·발 간격·무릎만 볼 수 있다.

## 포핸드
- 테이크백 — 체크: 몸통·어깨 약 90° 턴(발은 따라옴) / 머리는 그대로 / 왼손이 라켓을 밀어 올리고 오래 붙어 있음 → 몸을 가로질러 뻗음 /
  팔 백스윙은 짧게 / 뒤로 물러서지 않기. 실수: 팔로만 뺌, 팔 백스윙이 큼, 턴하며 뒤로 물러남, 머리가 같이 돎.
- 임팩트 — 체크: 손목이 몸(앞 골반·앞 어깨)보다 앞 / 팔 거의 펴짐 / 너무 앞도 안 됨(팔뚝–라켓 약 90°) / 임팩트 앞뒤 궤도가 곧음.
  실수: 늦은 타점(본인은 앞이라 느낌), 팔만 뻗음, 임팩트에서 감속.
- 피니시 — 체크: 왼손으로 왼어깨 위에서 라켓 받기 / 앞·왼쪽 약 45° 방향으로 몸을 감음 / 끝까지 가속 / 왼팔이 처지지 않음.
  실수: 스윙이 멈춤, 왼팔이 죽음, 늘 어깨 위로만 끝내려 함.

## 원핸드 백핸드
- 테이크백 — 체크: 약 90° 턴, 왼손이 라켓을 당겨 이끎 / 백스윙은 턴의 연장(따로 안 휘두름) / 풀 때 다리 → 골반 → 상체 / 앞발끝이 타점 쪽.
  실수: 힘이 들어감, 뒤로 크게 휘두름.
- 임팩트 — 체크: 손목이 앞발보다 앞(투핸드·포핸드보다 더 앞) / 팔 펴짐·몸은 옆 / 손목 고정. 실수: 늦은 타점, 손목으로 탑스핀.
- 피니시 — 체크: 몸 회전이 약 45°에서 멈춤(가슴이 타점 쪽) / 왼팔을 뒤로 뻗어 두 팔 일직선 / 뒷발을 앞발 뒤로 끎 / 머리가 잠깐 머묾.
  실수: 어깨·골반이 같이 열림, 팔로스루가 짧음.

## 투핸드 백핸드
- 테이크백 — 체크: 보자마자 어깨 턴, 옆으로 약 90° / 처음엔 팔이 조용 / 한손만큼 충분히 뒤로 / 물러서지 않고 축 회전.
  실수: 백스윙이 작음, 라켓을 밑으로 내린 채 뺌, 손목이 굳음, 면을 열고 뺌, 오픈 스탠스로 회전 부족.
- 임팩트 — 체크: 두 손목이 몸 앞 가장자리(앞 골반 선), 허리 높이쯤 / 골반이 어깨보다 먼저 돎 / 임팩트 뒤 두 팔이 펴짐.
  실수: 머리·몸이 기울어짐, 어깨·팔이 먼저 나감, 감속.
- 피니시 — 체크: 가슴이 타깃(코어 약 90° 회전) / 라켓이 반대쪽 어깨 위 10~15cm / 체중 앞발. 실수: 스윙이 멈춤, 뒤로 젖혀짐.

## 서브
- 플랫폼 vs 핀포인트 — 플랫폼: 두 발을 어깨너비로 벌린 채 끝까지, 체중 앞→뒤→앞, 트로피에서 두 다리로 같이 밀고 균형이 쉬움,
  토스는 1시 방향. 핀포인트: 토스·백스윙 동안 뒷발이 앞발 옆으로 모임, 체중 앞→뒤→두 발, 트로피에서 발이 모인 채 무릎이 굽음,
  앞으로 체중을 더 실음. 뼈대 판별: 두 발목 간 거리 ÷ 어깨 간 거리가 준비 → 트로피 사이에 줄어드는지(문턱값은 출처 없음).
- 준비 — 체크: 앞발 비스듬히·뒷발 베이스라인과 평행 / 발 간격 어깨너비 / 몸이 옆(열리지 않음) / 토스 손을 허벅지에 대고 시작.
  실수: 정면에 가깝게 섬, 포핸드 그립, 시작 자세가 매번 다름.
- 토스 — 체크: 토스 팔 곧게(팔꿈치 각) / 놓는 높이 눈높이~머리 위 약간 / 토스한 팔이 스윙 전까지 위 / 시작~임팩트 약 1.5~2.0초.
  실수: 팔을 굽힘, 일찍·늦게 놓음, 토스가 뒤로 넘어감(면이 열림), 가슴이 안 들려 옆에서 침.
- 트로피 — 체크: 치는 팔꿈치 약 90° / 라켓 손이 귀·머리 가까이 / 토스 팔 높이 + 어깨선 기울기 / 무릎 굽힘 / 발 간격(스탠스별).
  실수: 팔꿈치가 너무 높거나 낮음, 웨이터 쟁반, 몸을 덜·너무 돌림, 자세 만들려고 멈춤.
- 임팩트 — 체크: 팔 다 펴짐 + 어깨 위에 어깨 / 머리도 몸과 같이 기욺 / 몸은 타깃에 약 45° / 손목이 머리·앞발보다 앞 / 체중 앞발.
  실수: 낮은 타점에 팔 접힘, 머리를 세움·몸이 타깃을 봄, 손목 스냅, 공을 밂.
- 피니시 — 체크: 손목이 아래로 내려와 몸 반대쪽으로 / 앞발 착지 + 뒷발 뒤로 들림 / 코트 안쪽 착지 / 기울기 잠깐 유지.
  실수: 팔로스루가 오른쪽에서 멈춤(억지 회내), 팔이 굳음, 왼쪽으로 쓰러짐.

## 발리 (새로 추가)
- 준비 — 체크: 스플릿 뒤에도 전진 탄력 유지 / 두 손이 가슴 앞, 팔꿈치는 옆구리에서 떨어짐 / 라켓 헤드가 그립보다 위(뼈대로는 손 높이만).
  실수: 베이스라인식 스플릿으로 멈춤, 급히 달려들어 균형 없음, 팔꿈치를 안으로 붙임.
- 포핸드 발리 임팩트 — 체크: 상체 턴 약 45°(지나치지 않게) / 팔꿈치가 몸 선보다 앞 / 손목이 어깨선 뒤로 안 넘어감 /
  임팩트 손목이 앞 어깨보다 앞 / 스윙이 아니라 짧은 펀치 / 바깥발에 실었다가 안쪽 발 스텝.
  실수: 백스윙이 커서 팔꿈치가 뒤로(가장 흔함), 몸을 너무 돌려 타점이 뒤, 발이 상체보다 먼저.
- 백핸드 발리 임팩트 — 체크: 상체 턴 약 45° / 손이 어깨~턱 높이(라켓은 머리 높이) / 왼손이 라켓을 잡고 준비 / 팔꿈치 몸 앞 /
  팔꿈치가 살짝 굽었다 임팩트에 펴짐. 실수: 팔꿈치로 밂, 과한 턴, 공을 가로질러 휘두름.
- 피니시 — 체크: 치는 팔이 타깃 쪽으로 펴짐 / 어깨선이 더 열리지 않음 / (백핸드) 두 팔이 반대로 벌어짐 / 계속 앞으로.
  실수: 스트로크처럼 몸을 가로지르는 팔로스루, 어깨가 일찍 열림.

## 코치마다 말이 다른 곳
- 스플릿 착지: 임팩트 순간(Essential Tennis·Top Tennis Training) vs 임팩트 때 공중·직후 착지(Feel Tennis·Coachlife·Meike Babel).
- 스플릿 발 간격: 어깨너비 vs 어깨보다 넓게 vs 1.5~2배.
- 스탠스: 초보는 플랫폼·속도는 핀포인트(Tennis Beyond) / 플랫폼이 최선일 수 있다(Tennis Evolution) / 핀포인트가 체중을 더 싣는다(정진화).
- 토스 팔: 되도록 오래 위(Giffenig·이레슨) vs 오래 들면 에너지가 막힘(Essential Tennis). 놓는 높이: 눈높이 vs 머리 위 약간.
- 트로피 라켓: 끝이 위·팔꿈치 90°(Top Tennis Training) vs 비스듬히 머리 가까이(Feel Tennis) vs 트로피 자세를 만들지 말라(OTI).
- 포핸드 피니시: 어깨 위에서 받기 vs 가슴 가로지름 vs 상황 따라 4가지. 테이크백: 팔은 짧게 vs 크게 해야 시원하다(한국 레슨 일기).
- 발리 피니시: 타깃 쪽으로 뻗고 면 유지(Feel Tennis) vs 뻗지 말고 준비 자세로 복귀(TPA tennis) vs 펀치 후 멈춤(WebTennis24).

## 빈 곳
- 자막으로 다시 확인해야 한다. `meta.videos` 의 id 86개로 get_transcripts 만 다시 돌리면 된다(검색 한도와 무관).
- 한국어 레슨은 설명란뿐이라 얕다. Intuitive Tennis·Tom Avery·Tennis Evolution·2MinuteTennis 는 설명란에 핵심이 거의 없다.
- 코치가 숫자로 말한 것이 적다: 타점이 몸 앞 몇 cm, 무릎 각, 스플릿 높이·체공 시간, 발리 타점 높이는 어디에도 없다.
- 플랫폼·핀포인트 판별 문턱값, 스탠스별 임팩트 차이, 투핸드 백핸드 발리·하프 발리·높낮이별 발리는 비어 있다.
- 라켓 면·라켓 각이 들어간 체크포인트(트로피 라켓 끝, 면이 타깃, 손이 헤드보다 아래)는 뼈대로 못 잰다.
