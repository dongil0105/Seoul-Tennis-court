# ☁️ 클라우드 배포 안내 (친구 공유용 · 항상 켜진 앱)

내 PC가 꺼져도 친구들이 언제든 쓸 수 있는 **공개 대시보드**를 무료로 올리는 방법.
카드 없이, git 명령어 없이, 웹에서 클릭만으로 한다. (GitHub + Render, 둘 다 무료)

- 친구용은 **읽기 전용**(설정 변경 불가) + **카톡 알림 없음**(그건 내 PC 개인용 그대로).
- 코드는 이미 클라우드용으로 준비됨(`render.yaml`, `Dockerfile`, `.dockerignore`).

---

## PART 1. GitHub에 코드 올리기 (약 10분)

1. https://github.com 가입 (무료, 카드 X)
2. 우상단 **+** → **New repository**
   - Repository name: `tennis-alert` (아무거나)
   - **Private** 선택 가능(추천) → **Create repository**
3. 다음 화면에서 **"uploading an existing file"** 링크 클릭
4. 아래 항목을 **드래그해서 업로드**:
   - 📁 `app` 폴더
   - 📁 `scripts` 폴더
   - 📄 `requirements.txt`
   - 📄 `Dockerfile`
   - 📄 `render.yaml`
   - 📄 `.dockerignore`
5. 아래 **Commit changes** 클릭

> ⛔ **절대 올리면 안 되는 것** (비밀·불필요):
> `.env`(비밀번호·토큰!), `.venv`, `db`, `data`, `*.bat`
> → 위 5개 항목만 올리면 됩니다.

---

## PART 2. Render로 배포하기 (약 5분)

1. https://render.com 접속 → **Get Started** → **GitHub로 가입/로그인**
2. 상단 **New +** → **Blueprint**
3. 방금 만든 저장소(`tennis-alert`) 선택 → **Connect**
4. Render가 `render.yaml`을 읽고 설정을 자동으로 잡아줌
5. **SEOUL_API_KEY** 입력칸이 나오면 → 내 서울 열린데이터 인증키 붙여넣기
   (`.env`의 `SEOUL_API_KEY` 값 = `4a6b...` 그거)
6. **Apply** / **Create** → 빌드 시작 (몇 분 걸림, 로그가 흐름)
7. 완료되면 상단에 **공개 주소**가 생김:
   `https://seoul-tennis-alert.onrender.com` (비슷한 형태)

> `render.yaml` 대신 수동이면: New + → **Web Service** → 저장소 연결 →
> Runtime **Docker**, Plan **Free** → Environment에 `SEOUL_API_KEY`, `PUBLIC_READONLY=true`,
> `NOTIFY_ON_STARTUP=false`, `NOTIFY_ON_POLL=false` 추가 → Create.

---

## PART 3. 친구에게 공유

1. 위 공개 주소를 **카톡으로 친구에게 전송**
2. 친구는 그 링크를 **사파리/크롬으로 열고** → **홈 화면에 추가** → 앱 아이콘 완성
3. 내 PC가 꺼져 있어도 **항상 접속 가능** ✓

---

## 알아둘 점

- **무료 플랜은 15분간 아무도 안 들어오면 잠들어요.** 다음 사람이 열면 ~1분 깨어난 뒤(첫 로딩만 느림) 정상 작동. 자주 쓰면 대부분 깨어 있어요.
- 친구 화면은 **읽기 전용** — 코트 목록 보고 "예약하러 가기"로 yeyak 예약. 내 알림조건은 못 건드림.
- **카톡 알림은 클라우드에 없음** — 그건 내 PC(`테니스알림_시작.bat`) 개인용으로 계속 쓰면 됨.
- 서울 API 키는 Render에만 비밀로 저장(저장소엔 없음).
- 코드 바꾸면: GitHub에 파일 다시 업로드 → Render가 자동 재배포.
